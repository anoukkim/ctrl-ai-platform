# 직접 시연용 프롬프트 — 2026-11-04

ctrlai.my에서 그대로 복사해 붙여 넣는 프롬프트예요. 순서는 1 → 2 → 3. 막히면 「CTRL+AI 시연」 페이지(녹화본)로 넘어가면 돼요.

흐름: **1** 웹에서 해커톤 정보를 모아 표·차트로 → **2** Chat에서 "AI 퀴즈쇼" 게임을 만들고 말로 키우기 → Builder로 → **3** Builder에서 **모두가 같이 쓰는 앱**(공유 점수판 + 회원이 올리는 문제)으로 바꾸고 게시 → 모임에 온 사람들이 휴대폰으로 바로 참여.

## 시작 전

- ctrlai.my에 미리 로그인하고, 새 대화 열어 두기
- 남은 지원금 확인 — 전부 합쳐 대략 1,500~3,000원 (Builder 단계가 제일 큼)
- **한 번 끝까지 리허설** — 답은 매번 달라요. 리허설에서 만든 앱은 지우지 말고 "예비"로 남겨 두면, 본 시연에서 Builder가 오래 걸릴 때 바로 그걸 열면 돼요
- 녹화본 탭 열어 두기

**피할 것** (녹화하다 찾은 문제, 아직 안 고침):

- Chat 미리보기 안의 **지도**는 안 나와요 → 2번에는 지도 없음.
- Builder 앱 안의 **✦ AI 버튼**이 멈춘 적이 있어요 → 3번의 AI 문제 만들기는 마지막 선택 사항.
- 앱 AI 요금이 Usage에 바로 안 보인 적이 있어요 → Usage 화면은 녹화본으로 보여 주기.

## 1. 인터넷 검색 — 조사해서 표와 차트로 (Chat)

「도구」에서 **웹 사용**과 **코드 실행** 켜기, 「생각 과정 보기」도 켜 두면 좋아요. 모델은 「깊이 있는 답변」 추천.

```text
우리 AI 동아리가 올해 겨울에 팀을 꾸려서 대회에 나가 보려고 해. 웹에서 찾아서 정리해 줘.

1. 지금 참가 신청이 열려 있거나 곧 열리는 국내 대학생 대상 AI·코딩 해커톤이나 공모전 5개 — 주최, 신청 마감일, 대회 날짜, 상금, 참가 조건(팀 인원·전공 제한), 공식 링크를 표로. 마감이 이미 지난 건 빼 줘.
2. 코딩을 처음 해 보는 사람이 섞인 팀이 도전하기 좋은 곳 2개를 골라서 이유를 한 줄씩.
3. 최근 한 달 사이 나온 AI 소식 중에 대회 주제로 쓸 만한 것 3개 — 무슨 일인지 한 줄, 우리가 만들어 볼 수 있는 아이디어 한 줄.

모든 항목에 출처 링크를 달고, 확인이 안 되는 정보는 "확인 필요"라고 적어 줘.
```

이어서 (코드 실행으로 차트):

```text
1번 표에서 대회마다 신청 마감까지 며칠 남았는지 계산해서, 마감이 가까운 순서로 가로 막대 차트로 그려 줘. 막대 옆에 상금도 적어 줘.
```

보여 줄 곳: 생각 과정 → 검색하는 모습 → **출처 링크** → 영수증 줄 **검색 N회 · M원** → 차트.

## 2. Chat에서 게임 만들고 말로 키우기 → Builder로 (Chat)

새 대화 (웹 사용은 꺼도 돼요):

```text
동아리 모임에서 쓸 "AI 상식 퀴즈쇼" 웹페이지 만들어 줘.

- 시작 화면: 큰 제목, 팀 이름 2~4개를 적는 칸, 「시작」 버튼
- 문제는 AI·인터넷 상식 4지선다 10개 (쉬운 것부터 어려운 것 순서), 문제마다 15초 타이머 막대
- 팀이 돌아가면서 풀고, 맞히면 남은 시간만큼 보너스 점수
- 맞히면 초록색으로 반짝, 틀리면 화면이 살짝 흔들리고 정답을 보여 줘
- 위쪽에 팀별 점수판이 항상 보이고, 점수가 바뀔 때 숫자가 올라가는 애니메이션
- 마지막에 우승 팀 발표 화면과 「다시 하기」
- 어두운 배경에 네온 느낌, 키보드 1~4로도 답을 고를 수 있게
```

답 안의 **페이지 카드**를 눌러 오른쪽 미리보기에서 팀 두 개로 몇 문제 풀어 보기. 그다음 한 번에 여러 개 고치기:

```text
좋아, 이렇게 바꿔 줘.
1. 시작 화면에서 난이도(쉬움·보통·어려움)를 고르면 그 난이도 문제만 나오게, 난이도마다 10문제씩
2. 3문제 연속으로 맞힌 팀은 「🔥 콤보」 표시와 점수 2배
3. 문제마다 「50:50」 찬스 — 팀마다 한 번만, 누르면 오답 두 개가 사라져
4. 끝나면 팀별 점수를 막대 차트로 보여 주고, 문제마다 어느 팀이 맞혔는지 표로
5. 효과음도 넣어 줘 (정답, 오답, 시간 끝, 우승)
```

새 버전에서 난이도 고르기 → 50:50 → 콤보까지 보여 주고, 미리보기 아래 **「Builder로 보내기」**.

보여 줄 곳: 무엇을 바꿨는지 설명이 먼저 나오는 것, 답마다 든 돈, Builder로 넘어가는 데는 0원.

## 3. Builder에서 "모두가 같이 쓰는 앱"으로 (Project Builder)

Builder로 들어온 퀴즈쇼 프로젝트에서 (1~3분 걸려요 — 그동안 계획과 파일이 써지는 걸 설명):

```text
이 퀴즈쇼를 동아리 사람들이 각자 휴대폰으로 같이 쓰는 앱으로 키워 줘.

1. 「혼자 도전」 모드 추가: 한 사람이 10문제를 풀고, 끝나면 점수가 CTRL+AI 공유 데이터에 저장돼서 모두가 보는 「명예의 전당」(상위 10명, 이름·점수·난이도·날짜)에 올라가게. 로그인 안 한 사람은 순위를 볼 수만 있고, 저장하려고 하면 로그인하라고 안내해 줘.
2. 「문제 올리기」: 회원이 직접 4지선다 문제를 올리면 공유 문제 은행에 쌓이고, 「동아리 문제」 난이도를 고르면 그 문제들로 퀴즈가 나오게. 올린 사람 이름을 문제 옆에 작게.
3. 기존 팀 대결 모드는 그대로 두고, 첫 화면에서 「팀 대결 · 혼자 도전 · 명예의 전당 · 문제 올리기」 네 개를 고르게.
4. 휴대폰 세로 화면에서 버튼이 엄지로 누르기 편하게 크게.
```

보여 줄 곳: **만들 계획** → 파일을 하나씩 쓰는 모습(공유 데이터 목록을 적는 `ctrlai.json` 포함) → **점검** → 미리보기에서 혼자 도전 한 판 → 명예의 전당에 내 이름.

그다음 오른쪽 위 **「CtrlAIApps에 게시」** → 앱 주소를 화면에 띄우고 "지금 휴대폰으로 들어와서 한 판 해 보세요" → 명예의 전당에 사람들 이름이 쌓이는 걸 같이 보기. (미리보기의 데이터는 따로라서, 게시한 앱에서는 명예의 전당이 비어 있는 데서 시작해요.)

선택 — 앱 안의 AI까지 (위의 "피할 것" 참고, 리허설에서 잘 됐을 때만):

```text
「✦ AI 문제 만들기」 버튼을 넣어 줘. 주제를 한 단어 적고 누르면 AI가 그 주제로 4지선다 문제 5개를 만들어서 바로 퀴즈로 풀 수 있게. 버튼 옆에 1회 예상 금액을 보여 주고, 만든 문제는 마음에 들면 문제 은행에 올릴 수 있게 해 줘.
```

보여 줄 곳: 버튼 옆 "1회 약 N원", 누르면 **누른 사람의** 지원금에서 나가는 것.
