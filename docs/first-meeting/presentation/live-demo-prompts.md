# 직접 시연용 프롬프트 — 2026-11-04

ctrlai.my에서 그대로 복사해 붙여 넣는 프롬프트예요. 순서는 1 → 2 → 3이고, 막히면 「CTRL+AI 시연」 페이지(녹화본)로 넘어가면 돼요.

## 시작 전 (5분)

- ctrlai.my에 미리 로그인해 두고, 새 대화를 하나 열어 두기
- 왼쪽 아래 남은 지원금 확인 (세 단계 합쳐 대략 1,000원 안쪽)
- 발표 전에 한 번 끝까지 리허설하기 — 답은 매번 조금씩 달라요
- 녹화본 탭도 열어 두기 (막히면 바로 넘어가는 용도)

**피할 것** (녹화하다 찾은 문제, 아직 고치지 않음):

- Chat 미리보기 안의 **지도**는 안 나와요. 2번에는 지도를 넣지 마세요.
- Builder로 만든 앱 안의 **✦ AI 버튼**이 멈춘 적이 있어요. 3번의 AI 버튼은 넣고 싶을 때만, 마지막 선택 사항으로 해 주세요.

---

## 1. 인터넷 검색 (Chat)

입력창 아래 「도구」 → **웹 사용** 켜기. 그다음 보내기:

```text
오늘 기준으로 Anthropic이 최근에 발표한 Claude 소식을 웹에서 찾아서 3줄로 요약해 줘. 각 줄 끝에 출처 링크도 붙여 줘.
```

보여 줄 곳: 답 아래의 **출처 링크**, 그리고 영수증 줄의 **검색 N회 · M원**.

예비 (주제를 바꾸고 싶을 때):

```text
이번 주말 서울 날씨와 주말에 열리는 서울 행사 3개를 찾아서 표로 정리해 줘. 날짜·장소·한 줄 소개, 그리고 출처 링크까지.
```

## 2. 채팅으로 미리보기 → 다듬기 → Builder로 가져가기 (Chat)

새 대화에서 (웹 사용은 꺼도 돼요):

```text
점심 메뉴 룰렛 웹페이지 만들어 줘. 김치찌개, 돈까스, 쌀국수, 마라탕, 김밥, 햄버거, 초밥, 떡볶이 8개를 색깔 다른 원판에 넣고, 「돌리기」를 누르면 빙글빙글 돌다가 하나에 멈추면서 결과를 크게 보여 줘.
```

답 안의 **페이지 카드**를 눌러 오른쪽 미리보기에서 한 번 돌려 보기. 그다음 다듬기:

```text
좋아! 메뉴를 직접 추가하고 지울 수 있는 칸을 원판 옆에 넣어 주고, 멈추면 색종이가 터지는 효과도 넣어 줘.
```

새 버전 미리보기에서 메뉴 하나 추가 → 돌리기. 마음에 들면 미리보기 아래 **「Builder로 보내기」**.

보여 줄 곳: 답마다 든 돈(원 단위), "무엇을 바꿨는지" 설명이 먼저 나오는 것, Builder로 넘어가도 **여기까지 추가 비용 0원**인 것.

## 3. Builder에서 업데이트 (Project Builder)

Builder로 들어온 룰렛 프로젝트에서 보내기:

```text
휴대폰에서도 원판이 화면에 꽉 차게 보이도록 고쳐 주고, 위쪽에 「오늘 뭐 먹지?」 제목과 밝은 화면/어두운 화면 바꾸는 버튼을 넣어 줘. 결과가 나오면 아래에 지금까지 나온 결과 5개를 순서대로 보여 줘.
```

보여 줄 곳: **만들 계획** → 파일을 하나씩 쓰는 모습 → **점검** → 완성된 미리보기에서 돌려 보기. 끝나면 오른쪽 위 「CtrlAIApps에 게시」와 「내보내기」를 가리키기만 하고 (게시까지 하려면 시연 후 지우기).

선택 — 앱 안의 AI까지 보여 주고 싶을 때만 (위의 "피할 것" 참고):

```text
「✦ AI 추천」 버튼을 하나 넣어 줘. 누르면 지금 원판에 있는 메뉴 중에서 오늘 날씨와 기분에 맞는 걸 AI가 하나 골라서 이유와 함께 한 줄로 말해 줘.
```

- 시연 중 만든 대화·프로젝트는 지우기 (게시했다면 게시 취소 후 삭제)
- 이상했던 점은 의견 보내기나 `docs/first-meeting/README.md`의 "Found while recording"에 추가
