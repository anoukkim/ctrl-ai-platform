CTRL+AI 직접 시연

2026.11.04 1차 모임 · 프롬프트는 「복사」 → ctrlai.my에 붙여 넣기

녹화본 열기
준비 1 웹 검색 2 Chat → Builder 3 Builder · 진짜 AI 끝나고

1 웹에서 대회 정보를 모아 표·차트로 → 2 Chat에서 "AI 아이디어 코치" 화면을 만들고 말로 다듬기 (앱 안 AI는 아직 데모) → Builder로 → 3 Builder에서 진짜 AI(코칭·웹 검색)와 공유 데이터를 붙이고 게시 → 모두가 휴대폰으로 아이디어를 올리고 AI 코치를 써 봄.

시작 전

  • ctrlai.my에 로그인하고 새 대화 열어 두기
  • 남은 지원금 확인 — 전부 합쳐 대략 1,500~3,000원
  • 한 번 끝까지 리허설. 리허설에서 만든 앱은 "예비"로 남겨 두기 — Builder가 오래 걸리면 그걸 열면 돼요
  • 오늘 가입한 사람이 AI를 써 보게 하려면 Admin › Members에서 미리 승인
  • 녹화본 탭도 열어 두기

피할 것 · 막히면

  • Chat 미리보기 안의 지도는 안 나와요 — 지도는 넣지 않기.
  • Builder 앱의 ✦ AI 버튼이 안 보이거나 멈춘 적이 있어요. 먼저 앱 위쪽 CTRL+AI 줄의 실제 AI 스위치 확인 → 그래도 안 되면 CtrlAIApps의 「여행 일정 메이커」로 넘어가 앱 안 AI를 보여 주기.
  • 앱 AI 요금이 Usage에 바로 안 보인 적이 있어요 — Usage는 녹화본으로.
1

인터넷 검색 — 조사해서 표와 차트로

Chat · 새 대화
먼저 켜기: 도구 › 웹 사용도구 › 코드 실행생각 과정 보기 모델 깊이 있는 답변
1대회 조사
우리 AI 동아리가 올해 겨울에 팀을 꾸려서 대회에 나가 보려고 해. 웹에서 찾아서 정리해 줘.

1. 지금 참가 신청이 열려 있거나 곧 열리는 국내 대학생 대상 AI·코딩 해커톤이나 공모전 5개 — 주최, 신청 마감일, 대회 날짜, 상금, 참가 조건(팀 인원·전공 제한), 공식 링크를 표로. 마감이 이미 지난 건 빼 줘.
2. 코딩을 처음 해 보는 사람이 섞인 팀이 도전하기 좋은 곳 2개를 골라서 이유를 한 줄씩.
3. 최근 한 달 사이 나온 AI 소식 중에 대회 주제로 쓸 만한 것 3개 — 무슨 일인지 한 줄, 우리가 만들어 볼 수 있는 아이디어 한 줄.

모든 항목에 출처 링크를 달고, 확인이 안 되는 정보는 "확인 필요"라고 적어 줘.
2차트 같은 대화에 이어서
1번 표에서 대회마다 신청 마감까지 며칠 남았는지 계산해서, 마감이 가까운 순서로 가로 막대 차트로 그려 줘. 막대 옆에 상금도 적어 줘.
보여 줄 곳생각 과정 → 검색하는 모습 → 출처 링크 → 영수증 줄 「검색 N회 · M원」 → 차트
2

Chat에서 "AI 아이디어 코치" 만들기 → Builder로

Chat · 새 대화 (웹 사용은 꺼도 돼요)

말할 것: "채팅에서는 모양을 잡고, 진짜 AI는 Builder에서 붙여요." Chat 미리보기 안에서는 앱의 AI가 「데모」 답을 보여 줘요.

3화면 만들기
동아리 회원들이 만들고 싶은 앱 아이디어를 올리고, AI 코치가 그 아이디어를 만들 수 있게 도와주는 "아이디어 코치" 웹페이지 만들어 줘.

- 위쪽: 「아이디어 올리기」 칸 — 앱 이름, 한 줄 설명, 분류(공부·게임·생활·동아리·기타)
- 가운데: 올라온 아이디어 카드 목록 — 분류 색깔 태그, ❤️ 좋아요 수, 최신순/인기순 정렬, 분류 필터, 검색
- 카드를 누르면 오른쪽에 상세 보기가 열리고, 거기에 「✦ AI 코치에게 물어보기」 버튼
- AI 코치 결과는 이렇게 보여 줘: 한 줄 평, 난이도 별 1~5개, 꼭 필요한 기능 3~5개 체크리스트, 3단계 만들기 계획, 그리고 "CTRL+AI Chat에 그대로 붙여 넣을 첫 프롬프트" 상자와 「복사」 버튼
- 처음부터 예시 아이디어 5개가 들어 있게
- 깔끔한 어두운 화면, 카드에 살짝 떠오르는 효과

답 안의 페이지 카드를 눌러 미리보기 열기 → 카드 하나 열고 「✦ AI 코치」 → 데모 답 확인.

4다듬기 같은 대화에 이어서
좋아, 이렇게 바꿔 줘.
1. 상세 보기에 「🔎 비슷한 서비스 찾기」 버튼도 넣어 줘 — 이미 있는 비슷한 앱 3개와 우리 아이디어가 다른 점을 보여 주는 칸
2. 아이디어마다 진행 단계(아이디어 → 만드는 중 → 완성)를 바꿀 수 있게 하고, 위쪽에 단계별 개수 막대
3. 좋아요를 누르면 하트가 톡 튀는 애니메이션
4. 휴대폰 세로 화면에서는 상세 보기가 아래에서 올라오는 시트로

새 버전 확인 → 미리보기 아래 「Builder로 보내기」. 여기까지 넘어가는 데는 0원.

보여 줄 곳무엇을 바꿨는지 설명이 먼저 나오는 것 · 답마다 든 돈 · Builder로 넘어가는 데 0원
3

Builder에서 진짜 AI 붙이고, 모두가 쓰는 앱으로

Project Builder · 2~3분 걸려요 (그동안 계획과 파일이 써지는 걸 설명)
5진짜 AI + 공유 데이터
이 아이디어 코치를 CTRL+AI 기능 상자로 진짜 앱으로 만들어 줘.

1. 아이디어와 좋아요를 CTRL+AI 공유 데이터에 저장해서, 동아리 사람 모두가 같은 목록을 보게 해 줘. 올린 사람 이름을 카드에 작게. 로그인 안 한 사람은 보기만 할 수 있고, 올리거나 좋아요를 누르면 로그인 안내.
2. 「✦ AI 코치에게 물어보기」는 진짜 Claude로: "smart" 모델, 결과는 JSON 스키마로 받아서(한 줄 평, 난이도 1~5, 기능 목록, 3단계 계획, 첫 프롬프트) 지금 화면 그대로 채워 줘. 받은 코칭은 그 아이디어에 같이 저장해서 다음 사람은 다시 돈 쓰지 않고 볼 수 있게.
3. 「🔎 비슷한 서비스 찾기」는 웹 검색을 켜고 Claude가 실제로 찾아보게 해 줘. 결과마다 링크.
4. 각 AI 버튼 옆에 1회 예상 금액을 보여 주고, 끝나면 실제 든 금액을 결과 위에 작게.
보여 줄 곳
  • 만들 계획 → 파일을 하나씩 쓰는 모습 (공유 목록을 적는 ctrlai.json 포함) → 점검
  • 미리보기: AI 버튼 옆 「1회 약 N원 · 최대 M원」
  • 「✦ AI 코치」 → 진짜 코칭 + 「미리보기 사용 · N원 · 내 지원금에서」 (미리보기는 만든 사람이 내요)
  • 마무리: 「복사」한 첫 프롬프트를 새 Chat에 붙여 넣으면 그 아이디어로 또 앱이 만들어져요

게시하고 다 같이 써 보기

  • 오른쪽 위 「CtrlAIApps에 게시」 — AI 사용을 묻으면 「전체 기능」 고르기 (새 AI 앱은 「데모만」으로 시작해요)
  • 앱 주소를 화면에 띄우고 "휴대폰으로 들어와서 아이디어 하나씩 올려 보세요"
  • 각자 「✦ AI 코치」를 누르면 누른 사람의 지원금에서 나가요. 승인 전인 회원에게는 「데모」 답이 나와요
  • 게시한 앱의 데이터는 미리보기와 따로라서 빈 목록에서 시작해요
6선택 · 스케치 사진 리허설에서 잘 됐을 때만
아이디어 올리기에 「📷 스케치 사진」을 추가해 줘. 종이에 그린 화면 스케치를 찍어 올리면, AI 코치가 사진을 보고 화면 구성을 설명하고 빠진 기능을 짚어 주게. 사진은 저장하지 말고 코칭에만 써 줘.

끝나고

  • 시연용 대화·예비 프로젝트 정리
  • 이상했던 점은 docs/first-meeting/README.md의 "Found while recording"에 추가
