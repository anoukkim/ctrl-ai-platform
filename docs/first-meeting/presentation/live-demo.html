1대회 조사
우리 AI 동아리가 올해 겨울에 팀을 꾸려서 대회에 나가 보려고 해. 웹에서 찾아서 정리해 줘.

1. 지금 참가 신청이 열려 있거나 곧 열리는 국내 대학생 대상 AI·코딩 해커톤이나 공모전 5개 — 주최, 신청 마감일, 대회 날짜, 상금, 참가 조건(팀 인원·전공 제한), 공식 링크를 표로. 마감이 이미 지난 건 빼 줘.
2. 코딩을 처음 해 보는 사람이 섞인 팀이 도전하기 좋은 곳 2개를 골라서 이유를 한 줄씩.
3. 최근 한 달 사이 나온 AI 소식 중에 대회 주제로 쓸 만한 것 3개 — 무슨 일인지 한 줄, 우리가 만들어 볼 수 있는 아이디어 한 줄.

모든 항목에 출처 링크를 달고, 확인이 안 되는 정보는 "확인 필요"라고 적어 줘.
2차트 같은 대화에 이어서
1번 표에서 대회마다 신청 마감까지 며칠 남았는지 계산해서, 마감이 가까운 순서로 가로 막대 차트로 그려 줘. 막대 옆에 상금도 적어 줘.

3화면 만들기
동아리 회원들이 만들고 싶은 앱 아이디어를 올리고, AI 코치가 그 아이디어를 만들 수 있게 도와주는 "아이디어 코치" 웹페이지 만들어 줘.

- 위쪽: 「아이디어 올리기」 칸 — 앱 이름, 한 줄 설명, 분류(공부·게임·생활·동아리·기타)
- 가운데: 올라온 아이디어 카드 목록 — 분류 색깔 태그, ❤️ 좋아요 수, 최신순/인기순 정렬, 분류 필터, 검색
- 카드를 누르면 오른쪽에 상세 보기가 열리고, 거기에 「✦ AI 코치에게 물어보기」 버튼
- AI 코치 결과는 이렇게 보여 줘: 한 줄 평, 난이도 별 1~5개, 꼭 필요한 기능 3~5개 체크리스트, 3단계 만들기 계획, 그리고 "CTRL+AI Chat에 그대로 붙여 넣을 첫 프롬프트" 상자와 「복사」 버튼
- 처음부터 예시 아이디어 5개가 들어 있게
- 깔끔한 어두운 화면, 카드에 살짝 떠오르는 효과

→ 미리보기에서 확인

4다듬기 같은 대화에 이어서
좋아, 이렇게 바꿔 줘.
1. 상세 보기에 「🔎 비슷한 서비스 찾기」 버튼도 넣어 줘 — 이미 있는 비슷한 앱 3개와 우리 아이디어가 다른 점을 보여 주는 칸
2. 아이디어마다 진행 단계(아이디어 → 만드는 중 → 완성)를 바꿀 수 있게 하고, 위쪽에 단계별 개수 막대
3. 좋아요를 누르면 하트가 톡 튀는 애니메이션
4. 휴대폰 세로 화면에서는 상세 보기가 아래에서 올라오는 시트로

→ 「Builder로 보내기」

Builder에서 앱 안에 AI 붙이기

Project Builder
5AI 붙이기 · 같이 쓰기
이 아이디어 코치를 CTRL+AI 기능 상자로 진짜 앱으로 만들어 줘.

1. 아이디어와 좋아요를 CTRL+AI 공유 데이터에 저장해서, 동아리 사람 모두가 같은 목록을 보게 해 줘. 올린 사람 이름을 카드에 작게. 로그인 안 한 사람은 보기만 할 수 있고, 올리거나 좋아요를 누르면 로그인 안내.
2. 「✦ AI 코치에게 물어보기」는 진짜 Claude로: "smart" 모델, 결과는 JSON 스키마로 받아서(한 줄 평, 난이도 1~5, 기능 목록, 3단계 계획, 첫 프롬프트) 지금 화면 그대로 채워 줘. 받은 코칭은 그 아이디어에 같이 저장해서 다음 사람은 다시 돈 쓰지 않고 볼 수 있게.
3. 「🔎 비슷한 서비스 찾기」는 웹 검색을 켜고 Claude가 실제로 찾아보게 해 줘. 결과마다 링크.
4. 각 AI 버튼 옆에 1회 예상 금액을 보여 주고, 끝나면 실제 든 금액을 결과 위에 작게.
6추가 · 스케치 사진
아이디어 올리기에 「📷 스케치 사진」을 추가해 줘. 종이에 그린 화면 스케치를 찍어 올리면, AI 코치가 사진을 보고 화면 구성을 설명하고 빠진 기능을 짚어 주게. 사진은 저장하지 말고 코칭에만 써 줘.
