# ctrlai.my DNS 설정 안내 — 도메인 관리자용

`ctrlai.my`를 산 곳(도메인 등록 업체)의 관리 화면에서 할 일입니다. 서버를
몰라도 됩니다. **레코드 두 개를 넣고, 확인하면 끝**입니다. 10분이면 됩니다.

## 무엇을 하는 건가요

DNS는 "주소 → 서버 번호"를 알려 주는 전화번호부입니다. 지금은
`ctrlai.my`가 어느 서버도 가리키지 않습니다. 아래 두 줄을 넣으면 누가
`ctrlai.my`나 `www.ctrlai.my`를 열든 CTRL+AI 서버(`34.64.59.76`)로 갑니다.

## 넣을 레코드 — 정확히 이 두 개

| 이름(호스트, Name, Host) | 종류(Type) | 값(Value, Points to, Target) | TTL |
| --- | --- | --- | --- |
| `@` | **A** | `34.64.59.76` | 3600 (또는 기본값) |
| `www` | **CNAME** | `ctrlai.my` | 3600 (또는 기본값) |

- **`@`** 는 "도메인 그 자체(`ctrlai.my`)"라는 뜻입니다. 화면에 따라 이름 칸을
  **비워 두라**고 하거나 `ctrlai.my`를 적으라고 합니다 — 그 화면의 안내를
  따르세요.
- **`www`** 의 값은 화면에 따라 `ctrlai.my` 또는 끝에 점이 붙은
  `ctrlai.my.` 로 적습니다. 둘 다 같은 뜻입니다.
- `www`는 CTRL+AI 서버가 알아서 `https://ctrlai.my`로 넘겨 줍니다. 따로
  "포워딩"을 설정하지 마세요.

## 넣기 전에 지우거나 끌 것

등록 업체가 처음에 넣어 둔 기본 레코드가 새 레코드와 부딪힐 수 있습니다.
관리 화면의 레코드 목록을 보고:

| 보이는 것 | 할 일 |
| --- | --- |
| 이름이 `@` 또는 `www`인 다른 **A** 레코드 (주차 페이지, 업체 IP 등) | **삭제** |
| 이름이 `@` 또는 `www`인 **AAAA** 레코드 | **삭제** — 서버에 IPv6 주소가 없습니다. 남겨 두면 HTTPS 인증서 발급이 실패할 수 있습니다 |
| 이름이 `www`인 다른 **CNAME** | **삭제** (위의 `www` CNAME 하나만 남깁니다) |
| "도메인 주차(Parking)", "URL 포워딩/리다이렉트", "웹 포워딩" 설정 | **끄기** |
| **MX**, **TXT** 레코드 (메일, 인증용) | **그대로 둡니다** — 메일과 상관있는 것들입니다 |
| **NS** 레코드 | **절대 건드리지 않습니다** |

`api` 같은 다른 이름은 만들지 않습니다. 필요 없습니다.

## 확인하기

레코드를 저장하고 **5분쯤** 기다린 뒤 확인합니다. 업체에 따라 최대 몇
시간 걸리기도 합니다.

**Windows (PowerShell 또는 명령 프롬프트):**

```powershell
nslookup ctrlai.my 8.8.8.8
nslookup www.ctrlai.my 8.8.8.8
```

이렇게 나오면 성공입니다:

```text
이름:    ctrlai.my
Address:  34.64.59.76
```

```text
이름:    ctrlai.my
Address:  34.64.59.76
Aliases:  www.ctrlai.my
```

(`8.8.8.8`은 Google의 공개 DNS입니다. 내 PC나 회사 네트워크에 남아 있는
옛 기록 대신 바깥에서 보이는 최신 값을 물어봅니다.)

**브라우저로:** https://dnschecker.org 에서 `ctrlai.my`, 종류 `A`로 검색하면
세계 여러 곳에서 보이는 값이 나옵니다. 대부분이 `34.64.59.76`이면 됩니다.

**그다음:** 서버가 켜져 있으면 https://ctrlai.my 가 자물쇠와 함께 열립니다.
HTTPS 인증서는 서버가 DNS를 확인한 뒤 몇 분 안에 스스로 받습니다. 서버 쪽
일은 [`deployment.md`](deployment.md) 5단계입니다.

## 잘 안 될 때

| 증상 | 원인과 할 일 |
| --- | --- |
| `nslookup`이 다른 IP를 보여 줌 | 지우지 않은 옛 A 레코드나 주차 설정이 남아 있습니다. 위의 "지우거나 끌 것"을 다시 봅니다 |
| `Non-existent domain` / 찾을 수 없음 | 아직 퍼지는 중이거나 이름 칸을 잘못 적었습니다(`ctrlai.my.ctrlai.my`처럼 두 번 붙는 경우). 30분 뒤 다시 확인 |
| `ctrlai.my`는 되는데 `www`만 안 됨 | `www` CNAME이 없거나 값이 틀렸습니다 |
| 주소는 맞는데 사이트가 "안전하지 않음" | 인증서 발급 전입니다. 10~20분 기다립니다. 계속되면 서버 담당자에게 알려 주세요 |

## 바꾸면 안 되는 것

- 서버 IP(`34.64.59.76`)는 고정 IP라 바뀌지 않습니다. 레코드를 다시 고칠
  일은 서버를 옮길 때뿐입니다.
- 도메인 **만료일**을 확인해 두세요. 도메인이 만료되면 사이트가 통째로
  사라집니다. 자동 갱신을 켜 두는 것을 권합니다(💳 연 단위 비용).
