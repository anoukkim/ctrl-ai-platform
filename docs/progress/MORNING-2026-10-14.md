   ```bash
   # 서버에 접속한 뒤 (ctrlai_platform 사용자, ~/ctrl-ai-platform 폴더에서)
   ```

## (5) Claude API 키 넣기 (실제 Claude 켜기)

지금은 서버의 Claude가 **목업**이라 답장이 미리 정해진 한국어 문장으로
옵니다. 실제 Claude를 켜는 순서입니다.

1. **예전 키 삭제** — 이전에 채팅에 붙여 넣으셨던 키는 노출된 것으로
   간주합니다. https://console.anthropic.com → **API Keys** → 그 키의
   ⋯ 메뉴 → **Delete**.
2. **새 키 만들기** — 같은 화면의 **Create Key**. 키는 한 번만
   보여 주므로 바로 복사합니다. 어디에도 붙여 넣지 말고 4번에서 서버
   `.env`에만 넣습니다.
3. **크레딧 소액 구매 + 한도** — Console의 **Billing**:
   - 크레딧을 소액(예: $5–10)만 삽니다.
   - **Auto-reload는 꺼 둡니다** (잔액이 떨어져도 자동으로 더 사지
     않게).
   - **Monthly spend limit**(월 사용 한도)을 낮게 설정합니다. 키가
     새어도 피해가 그 금액에서 멈춥니다.
4. **서버 `.env` 수정** — 서버 접속 후:

   ```bash
   # 줄 번호로 바로 이동해 여는 법 (Ctrl+W는 브라우저 SSH 창을 닫아
   # 버리므로 쓰지 마세요. 검색이 필요하면 F6입니다.)
   grep -n "CLAUDE_PROVIDER\|ANTHROPIC_API_KEY" .env   # 줄 번호 확인
   nano +<그 줄 번호> .env
   ```

   - `CLAUDE_PROVIDER=anthropic`
   - `ANTHROPIC_API_KEY=` 뒤에 새 키
   저장(Ctrl+O, Enter) 후 종료(Ctrl+X). 그리고 권한 확인:

   ```bash
   ls -l .env    # -rw------- (600) 이어야 합니다
   chmod 600 .env
   ```

5. **api만 다시 시작**:

   ```bash
   docker compose -f docker-compose.prod.yml up -d --force-recreate api
   ```

6. **확인** — 관리자로 로그인해 Chat에서:
   - 기본 모델로 짧은 메시지 한 번, 모델을 **빠른 답변 (Haiku 4.5)**로
     바꿔 한 번. 진짜 Claude 답장이 오면 성공입니다.
   - **Usage**에 그 답장의 차감(몇 원 단위)이 보이고, 사이드바 지갑이
     그만큼 줄면 과금 연결도 정상입니다.
   - **키가 잘못되면**: 답장 대신 한국어 오류가 오고, 서버 로그
     (`docker compose -f docker-compose.prod.yml logs api | tail -20`)에
     인증 오류가 남습니다. 아무것도 차감되지 않습니다.
   - **되돌리기 한 줄**: `.env`에서 `CLAUDE_PROVIDER=mock`으로 바꾸고
     5번의 재시작 명령을 다시 실행하면 즉시 목업으로 돌아옵니다.
7. **주의 — 웹 검색 요금**: 실제 Claude가 켜지면 Chat의 웹 검색은 검색
   1,000회당 $10(약 1회 14원)의 **실제 요금**이 듭니다. 기본값은
   꺼짐이고, 관리자가 모델별로 켜 주기 전에는 아무도 쓸 수 없습니다.
   당분간 끄로 두시면 요금이 나갈 일이 없습니다.
