## (5) Claude API 키 넣기 (실제 Claude 켜기)

지금은 서버의 Claude가 **목업**이라 답장이 미리 정해진 한국어 문장으로
옵니다. 실제 Claude를 켜는 순서입니다.

1. **예전 키 삭제** — 이전에 채팅에 붙여 넣으셨던 키는 노출된 것으로
   간주합니다. https://console.anthropic.com → **API Keys** → 그 키의
   ⋯ 메뉴 → **Delete**.
2. **새 키 만들기** — 같은 화면의 **Create Key**. 키는 한 번만
   보여 주므로 바로 복사합니다. 어디에도 붙여 넣지 말고 4번에서 서버
   `.env`에만 넣습니다.
3. **크레딧 소액 구매 + 한도** — Console의 **Billing**:
   - 크레딧을 소액(예: $5–10)만 삽니다.
   - **Auto-reload는 꺼 둡니다** (잔액이 떨어져도 자동으로 더 사지
     않게).
   - **Monthly spend limit**(월 사용 한도)을 낮게 설정합니다. 키가
     새어도 피해가 그 금액에서 멈춥니다.
4. **서버 `.env` 수정** — 서버 접속 후:

   ```bash
   # 줄 번호로 바로 이동해 여는 법 (Ctrl+W는 브라우저 SSH 창을 닫아
   # 버리므로 쓰지 마세요. 검색이 필요하면 F6입니다.)
   grep -n "CLAUDE_PROVIDER\|ANTHROPIC_API_KEY" .env   # 줄 번호 확인
   nano +<그 줄 번호> .env
   ```

   - `CLAUDE_PROVIDER=anthropic`
   - `ANTHROPIC_API_KEY=` 뒤에 새 키
   저장(Ctrl+O, Enter) 후 종료(Ctrl+X). 그리고 권한 확인:

   ```bash
   ls -l .env    # -rw------- (600) 이어야 합니다
   chmod 600 .env
   ```

5. **api만 다시 시작**:

   ```bash
   docker compose -f docker-compose.prod.yml up -d --force-recreate api
   ```

6. **확인** — 관리자로 로그인해 Chat에서:
   - 기본 모델로 짧은 메시지 한 번, 모델을 **빠른 답변 (Haiku 4.5)**로
     바꿔 한 번. 진짜 Claude 답장이 오면 성공입니다.
   - **Usage**에 그 답장의 차감(몇 원 단위)이 보이고, 사이드바 지갑이
     그만큼 줄면 과금 연결도 정상입니다.
   - **키가 잘못되면**: 답장 대신 한국어 오류가 오고, 서버 로그
     (`docker compose -f docker-compose.prod.yml logs api | tail -20`)에
     인증 오류가 남습니다. 아무것도 차감되지 않습니다.
   - **되돌리기 한 줄**: `.env`에서 `CLAUDE_PROVIDER=mock`으로 바꾸고
     5번의 재시작 명령을 다시 실행하면 즉시 목업으로 돌아옵니다.
7. **주의 — 웹 검색 요금**: 실제 Claude가 켜지면 Chat의 웹 검색은 검색
   1,000회당 $10(약 1회 14원)의 **실제 요금**이 듭니다. 기본값은
   꺼짐이고, 관리자가 모델별로 켜 주기 전에는 아무도 쓸 수 없습니다.
   당분간 끄로 두시면 요금이 나갈 일이 없습니다.

## (7) 캐싱과 API 분배

**프롬프트 캐싱 점검(PART F) 결과** — 전부
[`audit-caching.md`](../archive/progress-2026-10-13/audit-caching.md)에 공식 문서 인용과 함께 있습니다:

- 우리 코드의 캐시 구조(중단점 2개, 바뀌지 않는 시스템 프롬프트, 계단식
  히스토리 자르기)는 공식 문서와 맞습니다. 두 턴의 요청 본문이 바이트
  단위로 같은 프리픽스를 갖는지 테스트로 박아 두었습니다.
- **고친 것 하나**: Sonnet 5.5의 캐시 읽기 요금 시드가 $0.20이었는데
  공식 가격은 **$0.10**입니다 — 그동안 캐시 읽기를 정가의 2배로 차감하고
  있었습니다. 시드와 마이그레이션으로 고쳤고, 지난 차감 기록은 역사라
  그대로 둡니다 — **보전하지 않기로 결정하셨습니다**(오전, 모두 목업·개발
  데이터였음).
- **Haiku 4.5는 최소 4,096토큰부터 캐시**가 됩니다(공식 문서). 우리
  시스템 프롬프트는 ~600토큰이라 **짧은 Haiku 대화는 캐시가 아예 안
  걸립니다** — 싼 모델이라 손해가 작아 그대로 두고 문서화만 했습니다.
- 새 화면: **Admin › AI Models › 비용 보정 › 캐시 절약** — 모델·날짜별
  적중률과 캐싱으로 아낀 금액(어림).

**실제 키를 넣은 뒤 캐싱이 도는지 확인하는 법** ((5)를 마친 뒤):
한 대화에서 짧은 메시지를 **2개 연달아**(5분 안에) 보내고, Admin › AI
Models › 비용 보정 › 캐시 절약에서 그 날의 "캐시에서 읽음"이 0보다 크면
정상입니다. 0이면: 두 메시지 사이가 5분을 넘었거나, Haiku에서 보냈거나
(4,096토큰 미만), `.env`의 `CHAT_PROMPT_CACHE`가 꺼진 경우입니다.

**API 분배 — 클럽 키 하나로 여러 회원이 쓰는 구조**는
[`docs/api-distribution.md`](../api-distribution.md)에 한국어로 정리해
두었습니다. 요점:

- 키는 **하나**, 서버 `.env`에만 있고 회원은 키를 보지 못합니다. 모든
  호출이 우리 백엔드를 지나며 회원·분기별로 기록됩니다.
- **회원별 한도 = 80,000원 지갑.** 최악의 경우 분기 비용 = 참여 인원 ×
  80,000원 (40명이면 3,200,000원/분기 ≈ $2,286, 월 약 $762). 실제
  예상치는 그보다 훨씬 낮고, Admin › Budget에서 집계를 봅니다.
- **한 회원이 클럽 크레딧을 빨아들이지 못하게 하는 다섯 겹**: 분당
  메시지 제한, 답장 1회 비용 한도, (켜면) 일일 한도, 호출 전 지갑 사전
  점검, 그리고 이번에 추가한 **동시 호출 제한**(프로세스당 3; Admin ›
  System에서 조절) — 넘치면 회원에게 "지금 요청이 많아요"라고 말하고
  아무것도 차감하지 않습니다.
- **클럽 크레딧이 바닥나면**: 회원은 한국어 안내를 보고 지갑은 차감되지
  않으며, Admin 대시보드에 "Claude — 크레딧 소진" 경고가 뜨고, 재시도는
  1회로 묶여 있어 API를 두들기지 않습니다.
- **Console 월 한도 권장**: 예상 지출의 2배쯤으로 Console에 설정하고,
  `.env`의 `ANTHROPIC_MONTHLY_BUDGET_USD`는 그보다 20% 낮게 — Admin ›
  Budget의 막대가 80%에서 경고합니다(KST 달 기준).
