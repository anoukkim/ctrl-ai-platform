# 출장·여행 준비 도우미

어디로, 언제 가는지 한 문장으로 쓰면(또는 칸을 고르면) **항공권 비교 버튼**, **현지 날씨**, **환율**, **준비물 체크리스트**를 한 화면에 모아 주는 앱이에요.

- 항공권: 날짜·인원을 채운 **네이버 항공권 · 구글 항공편** 검색을 새 창으로 열어요. 실시간 가격은 각 사이트에서 봐요(실시간 항공권 가격 데이터는 유료라 앱이 직접 가져오지 않아요).
- 날씨: [Open-Meteo](https://open-meteo.com) — 무료, 키 없음. 출발 2주 전부터 예보가 나와요.
- 환율: [Frankfurter](https://frankfurter.dev) — 유럽중앙은행 기준환율, 무료, 키 없음.
- CTRL+AI 안에서 위쪽 줄의 **실제 AI** 스위치를 켜면 「✦ AI로 정리」 버튼이 생겨요. Claude가 문장을 읽어 칸을 채워요 — 누를 때만, 내 지원금에서 몇 원.

## 열어 보기

압축을 풀고 `index.html`을 더블클릭하세요. 날씨·환율은 인터넷이 되면 바로 나와요. AI 버튼은 CTRL+AI 안에서만 생겨요.

## 파일

| 파일 | 하는 일 |
| ---- | ------- |
| `index.html` | 머리글, `데모 초기화` 버튼, 빈 `<main>`, 스크립트 두 개 |
| `style.css` | 밝은 "보딩 패스" 디자인, 860px·480px 반응형 |
| `js/data.js` | 목적지 31곳(이름·영어 이름·공항 코드·위치·통화), 출발지, 통화 표시 단위, 준비물 목록 |
| `js/app.js` | 화면, 저장, AI로 정리, 항공권 링크 만들기, 날씨·환율 불러오기 |

## 다음에 해 볼 만한 것

1. **목적지 늘리기** — `js/data.js`의 `PREP.DESTINATIONS`에 한 줄(이름, 영어 이름, 도시 공항 코드, 위도·경도, 통화)을 넣으면 목록과 링크·날씨·환율이 다 따라와요.
2. **일정을 캘린더에 넣기** — 가는 날·오는 날로 `.ics` 파일을 만들어 내려받게 하면 회사 캘린더에 바로 넣을 수 있어요.
3. **진짜 항공권 가격** — SPEC.md의 "Later": 서버를 두고 항공권 API(키 필요)를 붙여 최저가를 직접 보여 주기. 키는 서버에만 두세요.
