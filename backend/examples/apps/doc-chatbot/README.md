# 문서 챗봇 메이커

근로기준법이나 회사 규정 같은 문서을 올리면 **그 문서로만 답하는 챗봇**을 만들어요. 질문하면 문서에서 가장 잘 맞는 단락을 BM25라는 낱말 검색으로 찾아 그대로 인용하고, 출처(문서 이름 · 단락)를 붙여요. CTRL+AI 안에서 로그인한 회원이 **실제 AI**를 켜면 Claude가 그 단락들을 읽고 출처가 붙은 답을 정리해요(질문한 사람의 지원금에서, 보냈을 때만). 그 밖에서는 **데모** — 답은 문서 문장을 그대로 보여 줘요.

## 열어 보기

가장 쉬운 방법: 압축을 풀고 `index.html`을 더블클릭하세요. 챗봇 · 문서 · 설정 · 관리자 탭은 이렇게 열어도 잘 돼요.

**퍼가기 탭의 위젯 미리보기**는 다른 방법으로 열어야 해요. 파일로 열면(주소가 `file://`로 시작) 브라우저가 미리보기 칸에 파일을 불러오지 못하게 막아서 칸이 비어 보여요. 압축을 푼 폴더에서 터미널을 열고 아래 한 줄을 실행한 뒤 http://localhost:8000 을 여세요 (파이썬이 설치되어 있어야 해요).

```
python -m http.server 8000
```

`widget.html`을 바로 열면 위젯만 따로 떠요. 이건 어느 방법으로 열어도 되고, 이 기기에 저장된 문서와 설정으로 답해요(저장된 게 없으면 샘플 문서로). 다만 위젯 단독 화면에서 나눈 대화는 관리자 기록에 쌓이지 않아요.

처음 상태로 돌아가고 싶으면 위쪽의 **데모 초기화**를 두 번 누르세요 — 샘플 문서 2개, 처음 설정, 샘플 대화 기록 30개로 되돌아가요.

| `js/docs.js` | 샘플 문서(근로기준법 전문 — 국가법령정보센터, 2026. 10. 8. 시행), 챗봇 처음 설정, 샘플 대화 기록 30개, 질문 주제 나누기 규칙. |

| `js/widget.js` | 위젯의 동작. 미리보기 안에서는 만들기 화면이 보내 준 문서로 답해요. |

## 브라우저에만 저장돼요

올린 문서, 챗봇 설정(이름 · 말투 · 환영 메시지 · 못 찾을 때 문구), 대화 기록(최근 500개)은 모두 `doc-chatbot-v1`이라는 이름의 **한 묶음**으로, 지금 쓰는 브라우저에 들어가요. 어디에 넣는지는 앱을 어디서 여느냐에 따라 달라요.

- **CTRL+AI 안에서** 열면 CTRL+AI가 앱마다 마련해 주는 저장 공간(`ctrlai.storage`)에 넣어요. 이 앱만의, 이 브라우저(방문자)만의 공간이고 약 1MB까지 담겨요.
- **내려받은 파일을 직접** 열면 그 공간이 없으니, 브라우저의 저장 공간(localStorage)에 넣어요.

그래서

- 같은 컴퓨터, 같은 브라우저에서만 보여요. 다른 기기나 다른 사람과는 공유되지 않아요 — 다른 사람이 위젯을 열면 샘플 문서로 답해요.
- CTRL+AI에서 저장한 문서와 기록은 이 ZIP에 들어 있지 않고, 파일로 연 앱과도 이어지지 않아요.
- `index.html`을 더블클릭해서 열 때와 http://localhost:8000 으로 열 때도 저장 공간이 서로 달라요.
- 저장이 안 될 때(사이트 저장을 막아 둔 창이거나, CTRL+AI 안에서 약 1MB가 가득 찼을 때)는 "저장이 막혀 있어요"라고 알려 주고, 새로 고치면 사라져요.
