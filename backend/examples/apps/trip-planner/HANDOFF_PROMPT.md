첨부한 ZIP은 CTRL+AI에서 만든 내 웹앱이야.
- 앱 이름: 여행 일정 메이커
- 한 줄 설명: 서울·부산·제주 중 한 곳과 기간·인원·예산·취향을 고르면 날짜별 동선을 짜 주고, 시간표·동선 지도·예산 도넛·공유 링크까지 보여 주는 여행 계획 앱.

README.md에 앱 소개와 파일마다 하는 일이 있고, CLAUDE.md에 코드 구조(파일 불러오는 순서, 데이터 모양, 일정 짜는 규칙, 저장 방식)가 자세히 적혀 있어. HISTORY.md에는 지금까지 어떻게 바뀌어 왔는지, SPEC.md에는 이 앱의 원래 기획이 있어.
지금은 서버 없이 브라우저에서만 도는 HTML · CSS · JavaScript 정적 데모야. 일정은 AI가 아니라 정해진 규칙으로 짜는 데모 플래너(js/planner.js)가 만들고, "비 오는 날 버전으로 / 더 저렴하게 / 더 여유롭게" 세 문장만 알아들어. 지도도 지도 타일 없이 SVG로 단순하게 그린 거야. 이제는 그런 제한 없이 키워도 돼 — 서버, 데이터베이스, 진짜 AI나 진짜 지도를 붙여도 괜찮아.

부탁할게:
1. 먼저 파일들을 읽고, 이 앱이 지금 무엇을 하는지 세 줄로 정리해 줘.
2. 내가 추가하고 싶은 것을 어떻게 만들지 쉬운 말로 계획을 보여 줘. 나는 코딩을 잘 몰라서, 어려운 말은 풀어서 설명해 줘.
3. 위의 "내가 추가하고 싶은 것"이 비어 있으면, 이 앱에 맞는 아이디어를 2~3개 골라 줘. 예를 들면 경주 같은 도시 추가하기, 날짜별 일정을 메신저에 붙여 넣을 글로 복사하는 버튼, SPEC.md대로 Claude가 진짜로 일정을 짜는 버전. 각각 얼마나 어려운지도 알려 줘.
4. 내가 좋다고 하면, 바뀌는 파일을 하나씩 전체 내용으로 보여 주고, 어느 폴더에 어떤 이름으로 저장하는지도 알려 줘.
5. 마지막으로 내 컴퓨터에서 열어 확인하는 방법을 알려 줘. 지금은 index.html을 더블클릭하거나, 폴더에서 python -m http.server 8000을 실행하고 http://localhost:8000 을 열면 돼. 무엇을 눌러 보면 바뀐 게 잘 되는지도 같이 알려 줘.
