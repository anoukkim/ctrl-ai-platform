# 여행 일정 메이커

서울·부산·제주 중 한 곳을 고르고 기간, 인원, 총예산, 취향(맛집·자연·문화·쇼핑·휴식)을 정하면 하루하루 동선을 짜 주는 앱이에요. 날마다 시간표와 이동 시간, 진짜 지도 위의 동선(OpenStreetMap, 못 불러오면 손으로 그린 단순 지도), 예산 도넛이 함께 나오고, 카드를 끌어 순서를 바꾸거나 "비 오는 날 버전으로" 같은 문장으로 일정을 고칠 수 있어요.

서버 없이 브라우저에서만 돌아요. CTRL+AI 안에서 로그인한 회원이 **실제 AI**를 켜면 Claude가 일정을 짜고 문장도 알아들어요(그 사람의 지원금에서, 버튼을 눌렀을 때만). 그 밖에서는 정해진 규칙으로 짜는 "데모 플래너"가 만들고(같은 조건이면 늘 같은 일정), 화면에도 "데모 플래너"라고 표시돼 있어요.

## 열어 보기

가장 쉬운 방법: 압축을 풀고 `index.html`을 더블클릭하세요. 처음에는 예시 일정(부산 2박 3일, 2명, 60만 원, 맛집·자연)이 보여요.

화면이 비거나 일부가 안 되면, 압축을 푼 폴더에서 터미널을 열고 아래 한 줄을 실행한 뒤 브라우저에서 http://localhost:8000 을 여세요 (파이썬이 설치되어 있어야 해요).

```
python -m http.server 8000
```

- 오른쪽 위 **데모 초기화**를 두 번 누르면 처음 예시 일정으로 돌아가요 (한 번 누르면 "정말 지울까요? 한 번 더"로 바뀌어요).
- **공유 링크 만들기**로 만든 링크를 열면 그 일정이 **보기 전용**으로 열려요. 받은 사람은 "내 일정으로 가져오기"를 눌러야 고칠 수 있어요.

## 파일

| 파일 | 하는 일 |
| ---- | ------- |
| `index.html` | 첫 화면의 뼈대 — 머리글, 버튼 두 개(새 일정 만들기·데모 초기화), 스크립트 네 개를 차례로 불러와요. |
| `style.css` | 밤하늘 남색 + 산호색 "탑승권" 디자인. 좁은 화면(900px·560px 이하)에 맞춘 배치도 여기 있어요. |
| `js/places.js` | 세 도시의 장소 목록(이름, 위치, 취향, 실내 여부, 머무는 시간, 1인 비용, 한 줄 설명), 도시 윤곽, 이동 수단, 숙소 가격, 처음 예시 일정의 조건. |
| `js/planner.js` | 데모 플래너 — 일정 짜기, 시간표·이동 시간·예산 계산, 순서 바꾸기·추가·빼기, 문장 규칙 세 가지, 공유 링크 만들기와 읽기. |
| `js/anywhere.js` | "다른 곳" — 국내 어디든: 지도 검색으로 지역 찾기 → Claude가 갈 만한 곳 고르기(실제 AI, 1회) → 장소마다 지도 검색으로 진짜 위치 붙이기. CTRL+AI가 대신 검색해 주는 `/_ctrlai/places`를 써요. |
| `js/map.js` | 동선 지도 — 진짜 지도(Leaflet + CTRL+AI가 대신 받아 주는 OpenStreetMap 타일 — CTRL+AI 밖에서는 단순 지도)와 그게 안 뜰 때의 손으로 그린 SVG 지도 — 예산 도넛, 금액 표시(예: 12,300원). |
| `js/app.js` | 화면 그리기와 버튼 연결, 브라우저 저장, 끌어서 순서 바꾸기, 되돌리기, 공유 링크 복사. |
| `README.md` | 이 안내. |
| `CLAUDE.md` | Claude Code가 이 프로젝트를 이해하도록 쓴 안내. |
| `HANDOFF_PROMPT.md` | claude.ai에 붙여 넣을 프롬프트. |
| `HISTORY.md` | 버전 기록 — CTRL+AI가 내려받을 때 만들어 넣어요. |
| `SPEC.md` | 이 앱의 원래 기획. 서버와 실제 AI가 붙은 버전을 만들 때 쓰세요. |

## 브라우저에만 저장돼요

이 앱은 지금 일정, 보고 있던 날짜, 입력 화면에 적어 둔 조건을 `trip-planner-v1`이라는 이름표로, 지금 쓰는 브라우저에 넣어요. 어디에 넣는지는 앱을 어디서 여느냐에 따라 달라요.

- **CTRL+AI 안에서** 열면 CTRL+AI가 앱마다 마련해 주는 저장 공간(`ctrlai.storage`)에 넣어요. 이 앱만의, 이 브라우저(방문자)만의 공간이라 다른 앱과 섞이지 않고, 약 1MB까지 담겨요.
- **내려받은 파일을 직접** 열면 그 공간이 없으니, 브라우저의 저장 공간(localStorage)에 넣어요.

그래서

- 같은 컴퓨터, 같은 브라우저에서만 보여요. 다른 기기나 다른 사람과는 공유되지 않아요.
- CTRL+AI에서 저장한 일정은 이 ZIP에 들어 있지 않고, 파일로 연 앱과도 이어지지 않아요.
- `index.html`을 더블클릭해서 열 때와 `http://localhost:8000`으로 열 때도 저장 공간이 서로 달라요.
- "되돌리기"는 저장되지 않아요. 새로 고침하면 바로 전 일정으로는 돌아갈 수 없어요.

다른 사람에게 보여 주려면 공유 링크를 쓰세요. 일정 전체가 주소의 `#share=` 뒤에 그대로 들어가요 — 어디에도 보내지 않고, 링크 자체가 일정이에요. 그래서 링크가 꽤 길어요.

## 다음에 해 볼 만한 것

1. SPEC.md의 원래 기획대로 **진짜 버전** 만들기 — 서버(예: FastAPI)와 데이터베이스(예: PostgreSQL)를 두고, Claude API가 조건과 문장 요청을 이해해 일정을 짜게 하고, 단순 지도 대신 실제 지도를 붙이기. 일정을 계정에 저장해 다른 기기에서도 볼 수 있게.
2. **자주 가는 도시를 고정 카드로** (예: 경주) — "다른 곳"으로 AI가 고른 장소가 마음에 들면 `js/places.js`에 장소 목록과 단순한 윤곽, 이동 수단, 숙소 가격을 적어 두세요. 입력 화면에 도시 카드가 하나 더 생기고, 그 도시는 AI 없이(0원) 바로 짜져요.
3. **일정을 글로 복사하기** — "글로 복사" 버튼을 눌러 날짜별 시간·장소·예상 비용을 메신저에 바로 붙여 넣을 수 있는 짧은 글로 만들어 주기. 인쇄했을 때 깔끔하게 나오는 인쇄용 스타일도 함께.
