첨부한 ZIP은 CTRL+AI에서 만든 내 웹앱이야.
- 앱 이름: 영수증 가계부
- 앱 설명: 영수증 사진을 올리면 상호·날짜·품목·금액·카테고리를 읽어 가계부에 넣고, 카테고리 예산과 차트, 이번 달 소비 패턴까지 보여 주는 앱이야.

ZIP 안의 README.md에 앱 설명과 열어 보는 방법이, CLAUDE.md에 코드 구조와 "AI가 들어갈 자리"가 정리돼 있어. HISTORY.md에는 지금까지 어떻게 바뀌어 왔는지, SPEC.md에는 이 앱의 원래 기획(FastAPI 서버 + PostgreSQL + Claude API로 영수증 읽기)이 있어.
지금은 서버 없이 브라우저에서만 돌아가는 HTML · CSS · JavaScript 데모야. 영수증 읽기 결과랑 소비 패턴 글은 샘플 영수증 12장에 맞춰 미리 만들어 둔 거고, 기록은 이 브라우저에만 저장돼 (CTRL+AI 안에서는 ctrlai.storage, 파일로 열면 localStorage). 이제는 그런 제한 없이 키워도 돼 — 서버나 데이터베이스, 진짜 AI를 붙여도 괜찮아.
