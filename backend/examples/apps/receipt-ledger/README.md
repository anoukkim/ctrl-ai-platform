# 영수증 가계부

영수증 사진을 올리면 상호·날짜·품목별 금액·카테고리를 읽어 가계부에 넣고, 카테고리별 예산과 차트, 이번 달 소비 패턴까지 보여 주는 앱이에요.
지금은 서버 없이 브라우저에서만 도는 **정적 데모**예요. "AI가 읽은 결과"와 "소비 패턴 분석"은 미리 만들어 둔 것이고, 그런 자리에는 **데모** 배지가 붙어 있어요.
지금까지 어떻게 바뀌어 왔는지는 `HISTORY.md`에 있어요.

## 열어 보기

가장 쉬운 방법: 압축을 풀고 `index.html`을 더블클릭하세요. 브라우저에서 바로 열려요.

화면이 비거나 일부가 안 되면, 압축을 푼 폴더에서 터미널을 열고 아래 한 줄을 실행한 뒤 브라우저에서 http://localhost:8000 을 여세요 (파이썬이 설치되어 있어야 해요).

```
python -m http.server 8000
```

처음 열면 3달 치 예시 내역과 샘플 영수증 12장이 들어 있어요. 이것저것 눌러 본 뒤 처음 상태로 돌리고 싶으면 왼쪽 아래 **데모 초기화**를 두 번 누르세요 (한 번 누르면 "다시 누르면 처음으로"로 바뀌어요).

## 브라우저에만 저장돼요

내역(영수증 기록 전부)과 카테고리별 예산은 브라우저의 저장 공간(localStorage)에 하나로 묶여 저장돼요. 저장 이름은 `receipt-ledger-v1:` 뒤에 **앱이 있는 폴더 주소**를 붙인 것이에요 (예: http://localhost:8000 으로 열면 `receipt-ledger-v1:/`). 그래서

- 같은 컴퓨터, 같은 브라우저에서만 보여요. 다른 기기나 다른 사람과는 공유되지 않아요.
- `index.html`을 더블클릭해서 열 때와 http://localhost:8000 으로 열 때는 주소가 달라서 저장 공간도 서로 달라요. 더블클릭으로 열 때는 폴더를 옮기거나 이름을 바꿔도 주소가 바뀌어서 처음 데모 상태로 보여요.
- CTRL+AI(apps.ctrlai.my)에서 써 둔 내역은 이 ZIP에 들어 있지 않아요. 옮기고 싶으면 그쪽 **내역** 화면에서 **CSV 내려받기**로 받아 두세요 (엑셀에서 한글이 바로 보여요).
- 브라우저의 방문 기록·사이트 데이터를 지우면 내역도 같이 지워져요.

## 다음에 해 볼 만한 것

1. **SPEC.md대로 진짜 버전 만들기** — FastAPI 서버와 PostgreSQL 데이터베이스를 붙이고, 올린 영수증 사진을 Claude API(이미지 읽기)에 보내 상호·날짜·품목·합계·카테고리를 실제로 뽑아 오게 해요. 이번 달 소비 패턴 글도 Claude가 실제 내역을 보고 쓰게 바꿔요.
2. **내 카테고리 추가하기** — 예를 들어 "반려동물"이나 "구독료". `js/data.js`의 카테고리 목록, 색, 처음 예산 세 곳에 한 줄씩 넣으면 도넛·예산 막대·필터에 바로 나타나요.
3. **백업 파일로 내보내기·불러오기** — 지금 내역과 예산을 파일 하나로 저장하고, 다른 브라우저나 기기에서 그 파일을 불러와 이어 쓰게 해요. 위에서 말한 "저장 공간이 서로 다른" 문제도 해결돼요.
