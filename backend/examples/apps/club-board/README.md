# 동아리 게시판

카카오톡 채팅방처럼 생긴 동아리 게시판이에요. 공지·자유·질문으로 나눠 글을 쓰고, 댓글과 반응(👍 ❤️ ✅)을 남겨요. 새 글은 15초마다 확인해서 알려 주고, 지난번에 본 뒤 올라온 글에는 **N**이 붙어요.

- 글·댓글·반응은 CTRL+AI의 공유 저장소(`ctrlai.db`)에 있어서 모든 회원이 같이 봐요. 읽기는 누구나, 쓰기는 CTRL+AI 회원만.
- 위쪽 CTRL+AI 줄에서 **실제 AI**를 켜면: 질문 글에 「✦ AI 답변 초안」(댓글 칸에 초안을 채워 줘요 — 다듬어서 보내요), 댓글이 3개 넘는 글에 「✦ AI 3줄 요약」. 누를 때만, 누른 사람의 지원금에서 몇 원.

## 열어 보기

압축을 풀고 `index.html`을 더블클릭하세요. CTRL+AI 밖에서는 예시 글로 돌아가는 **데모**예요(새로 고치면 처음으로).

## 파일

| 파일 | 하는 일 |
| ---- | ------- |
| `index.html` | 노란 상단바, 분류 탭, 글쓰기 창, 목록·글 화면 자리 |
| `style.css` | 카톡 같은 말풍선, 날짜 구분선, 아래에 붙은 댓글 입력창 |
| `ctrlai.json` | 공유 목록 세 개(posts, comments, reactions)를 CTRL+AI에 알려요 |
| `js/app.js` | 불러오기·쓰기·반응·새 글 확인·AI 초안과 요약 |

## 다음에 해 볼 만한 것

1. **분류 바꾸기** — `CATEGORIES`와 `index.html`의 탭을 "공지 · 맛집 · 스터디"처럼 우리 모임에 맞게.
2. **검색** — 목록 위에 검색칸을 두고 제목·본문으로 거르기.
3. **AI 한 가지 더** — 공지 글에 「✦ AI로 다듬기」(맞춤법·말투 고치기)를 붙여 보기.
