# CTRL+AI — Frontend

Next.js + React + TypeScript web portal for CTRL+AI.

Setup and startup for the whole stack live in the
[repository README](../README.md). In short, from this directory:

```powershell
npm.cmd install
npm.cmd run dev      # http://localhost:3000
```

The dev server proxies `/api/*` to the FastAPI backend (default
`http://localhost:8000`; override with `BACKEND_ORIGIN`), so the browser
sees one origin and the session cookie stays HttpOnly.

## Layout

| Path | Purpose |
| ---- | ------- |
| `app/page.tsx` | Chat — the opening screen after login |
| `app/builder/`, `app/video/` | The two workspaces and their libraries |
| `app/ctrlaistore/`, `app/ctrlaitube/` | Community screens (listings still mock until Phases 5/8) |
| `app/usage/`, `app/profile/`, `app/login/`, `app/signup/` | Account screens |
| `app/admin/` | Admin sections — named once in `app/admin/sections.ts` |
| `app/components/` | Shared UI (AppShell, ChatWorkspace, ConfirmDialog, …) |
| `lib/` | Typed API clients and helpers — network calls never live in components |
| `__tests__/` | Vitest + Testing Library |

## Checks

```powershell
npm.cmd test
npx tsc --noEmit
npm.cmd run lint
npm.cmd run build
```
