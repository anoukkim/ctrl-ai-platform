# Ctrl AI — Frontend

Next.js + React + TypeScript web portal for Ctrl AI.

Setup and startup instructions for the whole stack live in the
[repository README](../README.md). In short, from this directory:

```powershell
npm install
npm run dev      # http://localhost:3000
```

The frontend expects the FastAPI backend at `http://localhost:8000`. See
`.env.local.example` to point it somewhere else.

## Layout

| Path                         | Purpose                                        |
| ---------------------------- | ---------------------------------------------- |
| `app/page.tsx`               | Placeholder dashboard (Server Component)       |
| `app/components/`            | UI components, including the backend status card |
| `lib/api.ts`                 | Typed client for the Ctrl AI backend           |

Network calls belong in `lib/`, not in components, so the UI never
contains URLs and response shapes are declared in one place.

## Checks

```powershell
npx tsc --noEmit
npm run lint
npm run build
```

`AGENTS.md` and `CLAUDE.md` in this directory are generated by `next dev`
and contain Next.js version guidance for AI coding tools.
